Cloud needs your own free Supabase project setup. See setup guide below.
One-time free setup instructions
  1. Create a free project at Supabase.
  2. Copy its Project URL and publishable (anon) key into the fields above.
  3. In Supabase SQL Editor, run this SQL:
create table if not exists public.player_saves (
 user_id uuid primary key references auth.users(id) on delete cascade,
 save_data jsonb not null,
 updated_at timestamptz not null default now()
);
alter table public.player_saves enable row level security;
create policy "Players manage their own save"
on public.player_saves for all to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
Use only the publishable/anon key in this browser game. Never paste a service-role or secret key. Enable email/password sign-in in Supabase Auth. If email confirmation is enabled, confirm the signup email before signing in.
